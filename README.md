# MapRun

Офлайн-трекер пробежек для Android: живая карта, GPS-запись в фоне, история, тепловая карта маршрутов, ачивки и виджет на рабочий стол.

Данные остаются на телефоне. Облака, аккаунта и API-ключа для карт нет.

| | |
|---|---|
| Язык | Kotlin |
| UI | Jetpack Compose, Material 3 |
| Карты | MapLibre Native + тайлы [OpenFreeMap](https://openfreemap.org) |
| Архитектура | MVVM + Clean Architecture |
| DI / БД | Hilt, Room, DataStore |
| minSdk / targetSdk / compileSdk | 26 / 34 / 35 |

Пакет: `com.example.runner`

---

## Возможности

**Запись**
- Полноэкранная карта и точка GPS в реальном времени
- Старт с отсчётом 3–2–1, пауза, продолжить, стоп с подтверждением
- Живые цифры: время, дистанция, темп, скорость, калории, набор высоты, текущий километр
- Сравнение с средним темпом: быстрее / ровнее / медленнее
- Автопауза, если скорость ниже 0.5 м/с дольше 10 секунд
- Голосовые сплиты на русском (склонения), фразы на старте и финише
- Призрак лучшей прошлой пробежки, если старт рядом
- Челлендж дня с прогрессом прямо на карте
- Экран не гаснет во время записи
- Foreground-сервис: маршрут пишется и в свёрнутом приложении

**После финиша**
- Пробежка сохраняется сразу, даже если экран финиша не успел открыться
- Карта маршрута, статистика, график скорости, километровые отрезки
- Сравнение с прошлой пробежкой и отметка личных рекордов
- Предпросмотр ачивок
- Экспорт GPX, карточка с фото маршрута и текстовая сводка

**История и прогресс**
- Лента по дням, сводка недели, лучший темп недели, удаление свайпом
- Детали тренировки с картой, графиками и шарингом
- Статистика недели и месяца, личные рекорды
- Тепловая карта всех маршрутов, фильтр «всё / неделя»
- Ачивки с прогресс-барами и ежедневный челлендж
- Виджет: километры недели, число тренировок, быстрый старт

**Настройки**
- Километры или мили
- Вес для калорий
- Тема: системная / светлая / тёмная
- Интервал голосовых подсказок
- Автопауза вкл/выкл

## Как устроен проект

```
app/src/main/java/com/example/runner/
├── RunnerApp.kt              # Hilt + инициализация MapLibre
├── MainActivity.kt           # edge-to-edge, виджет, экран не гаснет
├── di/                       # Room, репозитории
├── domain/                   # модели, use case, формулы
├── data/                     # Room, DataStore, локация, мапперы
├── service/                  # TrackingManager, FGS, TTS
├── presentation/             # экраны и ViewModel
├── widget/                   # Glance-виджет недели
└── ui/theme/                 # цвета, типографика, тема
```

Слои не ходят друг к другу напрямую: UI читает use case и репозитории через Hilt, запись GPS идёт в `TrackingManager`, сервис только кормит его точками.

**Фильтры GPS.** Точка отбрасывается, если точность хуже 30 м или скорость выше 30 км/ч. Расстояние — гаверсинус. Калории: `вес × км × 1.036`.

**Карты.** Стили Liberty / Dark с `tiles.openfreemap.org`. Ключ не нужен, интернет для тайлов нужен.

## Что нужно для сборки

1. [Android Studio](https://developer.android.com/studio) Ladybug / новее (AGP 8.7, JDK 17)
2. JDK 17 — подойдёт встроенный JBR из Studio
3. Android SDK:
   - Platform API 35 (compile)
   - Platform API 34 желательно
   - Build-Tools, Platform-Tools
   - Google Play services
4. Телефон с Android 8+ или AVD **с Google Play**

`local.properties` Android Studio создаёт сама. В git его нет.

Лучше гонять на телефоне: GPS и фон ведут себя честнее, чем на эмуляторе.

## Скачать APK

Готовый файл лежит в [Releases](https://github.com/zibirik/maprun/releases): бери свежий `MapRun-1.1.0.apk`.

На Android 8+ разреши установку из неизвестных источников, открой APK и поставь.  
Подпись debug — на свой телефон ставится, в Play Store такой файл не принимают.

## Сборка

### Android Studio

1. **File → Open** — папка с `settings.gradle.kts`
2. Дождись Gradle Sync (первый раз качает Gradle 8.9)
3. Выбери устройство → **Run**
4. Разреши геолокацию и, на Android 13+, уведомления

Debug-APK: `app/build/outputs/apk/debug/app-debug.apk`

### Терминал

```bat
gradlew.bat assembleDebug
gradlew.bat installDebug
```

Release без своей подписи: `gradlew.bat assembleRelease`. Minify выключен.

## Первый запуск

1. Дай доступ к геолокации — без него запись не начнётся
2. Дождись фикса (чип `±10 м` — хороший сигнал, стартовать можно и раньше)
3. **Старт** → отсчёт 3–2–1
4. Сверни приложение: в шторке есть пауза и стоп
5. Стоп → экран финиша. Пробежка уже в истории, кнопка **Готово** ведёт в ленту

На карте до старта видны приветствие, километры недели, серия дней и последняя тренировка.

## Виджет

Долгий тап по рабочему столу → виджеты → **MapRun**.  
Тап открывает приложение и запускает отсчёт (`runner://start`).

## Разрешения

| Разрешение | Зачем |
|---|---|
| Точная / примерная геолокация | Маршрут и точка на карте |
| Foreground service + location | Запись, когда приложение свёрнуто |
| Уведомления (Android 13+) | Шторка с паузой и стопом |
| Интернет | Тайлы карты |
| Wake lock | Экран не гаснет на пробежке |

Фоновой геолокации «всегда» нет: хватает fine location + FGS.

## Частые проблемы

**Серая карта** — нет сети или режется HTTPS. Тайлы: `https://tiles.openfreemap.org`.

**Нет GPS на эмуляторе** — нужен образ с Google Play. В настройках эмулятора задай координаты.

**Сервис убивается на Xiaomi / Huawei / Samsung** — разреши автозапуск и сними лимит фона для MapRun.

**`sdk.dir` not found** — один раз открой проект в Android Studio, она пропишет SDK.

**Gradle / TLS** — проверь сеть и VPN. File → Invalidate Caches → Restart.

**Телефон не виден** — USB-отладка, другой кабель, `adb devices`.

**Вылет на стопе (1.0.0)** — исправлено в 1.1.0. На Android 12+ стоп больше не поднимает foreground-сервис заново, маршрут пишется в базу сразу, карта финиша больше не падает на границах.
